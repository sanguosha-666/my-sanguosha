# 组队模式（team）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增"组队模式"（简化团队战：队友公开、自由选队、胜负按队、SEATS 扩到 9），并把"主公局"改名为"身份局"、AI 提示词适配组队玩法。

**Architecture:** 新增 `gameMode='team'` + `p.team`（队伍号）+ `g.teamCount`，大厅自由选队/房主指定机器人进队，`checkWin` 按存活队伍数判胜负。完全复用现有全局作用域多文件结构（无模块），身份/乱斗分支全部不动。

**Tech Stack:** 纯浏览器 JS（全局作用域），Firebase Realtime Database，vm 沙箱测试（node）。

**Spec:** `docs/superpowers/specs/2026-08-10-team-mode-design.md`

## Global Constraints

- 分支纪律：**所有 commit/push 只到 `wenwen_dev`**，main/chengcheng 绝不动（用户纪律："我不说合并main绝对不可以合并"）。
- 全项目无全局 `g`：函数里裸 `g.` 必崩；用 `currentG` 或参数传递。
- 状态变更必须走 `tx(fn)`；新增持久化字段必须在 `normalize(g)` 补默认（Firebase 吞空数组/undefined 拒绝写入）。
- 隐藏信息红线：手牌/未揭身份等不泄露；队伍号是**公开信息**（所有玩家可见，与身份不同，无 reveal 机制）。
- 机器人回归红线：无密钥本地 fallback 行为**零变化**；`botSeatForState` 不因 team 改动行为变化。
- 身份模式（identity）分支全部有 `gameMode==='identity'` 守卫，team 改动不得触碰这些守卫逻辑。
- 测试运行：`node run_ai_test_button_test.js` 等套件；顶层 await 会触发 node ESM 检测，测试文件内用 async IIFE 包裹（参照现有套件惯例）。
- 版本号：改 `data.js`/`game.js`/`render.js`/`render-controls.js`/`bot.js`/`bot-ai-bus.js` 内容后 `index.html` 所有 `?v=N` 同步 +1（当前 348）。

```js
// joinTeam(team):组队模式大厅选队(玩家自由选队,先到先得)。tx 写自己 p.team,
// teamCount 由 normalize 推导(不手写,靠 normalize 收口)。队伍号 < SEATS(一人一队上限)。
function joinTeam(team){
  tx(g=>{
    if(g.started || g.phase!=='lobby' || g.gameMode!=='team') return g;
    if(!Number.isInteger(team) || team<0 || team>=SEATS) return g;
    if(!g.players[mySeat]) return g;
    g.players[mySeat].team = team;
    return g;
  });
}
// createNewTeam:建一个新队伍并入队。队伍号 = 当前 teamCount(由 normalize 保证整数)。
function createNewTeam(){
  tx(g=>{
    if(g.started || g.phase!=='lobby' || g.gameMode!=='team') return g;
    const team = Number.isInteger(g.teamCount) ? g.teamCount : 0;
    if(team>=SEATS) return g;
    if(!g.players[mySeat]) return g;
    g.players[mySeat].team = team;
    return g;
  });
}
```

```js
function addBot(team){
  tx(g=>{
    if(g.started || g.phase!=='lobby' || mySeat!==0 || g.players.length>=SEATS) return g;
    const botNo=g.players.filter(p=>p&&p.isBot).length+1;
    const botTeam = (g.gameMode==='team') ? (Number.isInteger(team)&&team>=0&&team<SEATS ? team : null) : null;
    g.players.push({
      name:'机器人'+botNo,cid:'bot-'+Date.now()+'-'+Math.floor(Math.random()*1000000),
      isBot:true,botLevel:'smart',hp:MAX_HP,maxHp:MAX_HP,hand:[],alive:true,team:botTeam
    });
    g.log=pushLog(g.log,'已添加机器人'+botNo);
    return g;
  });
}
```
