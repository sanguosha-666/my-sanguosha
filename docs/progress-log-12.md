- **CORE-146 收尾两项：`.gitignore` 按工件类别补全 / 把"零余量"从 log 记录升级成规则化断言**：
  - **① `.gitignore` 不再只堵单个洞**。上一条只加了 `node_modules`，那是堵掉已经发生的那一个洞。**真正的根因是"本项目没有 package.json、长期也就没有真正的 `.gitignore` 兜底，而改动收尾惯用 `git add -A`"——两者相加的结果是任何落在项目根的临时工件迟早会被误提交**，与具体是哪一个无关。所以按**工件类别**一次列全这几轮实际产生过的：依赖软链（`node_modules`）、验证脚本的截图/录像输出（`*.png`/`*.jpeg`/`screenshots/` 等，**但用 `!assets/**/*.png` 保留真正入库的站点素材**）、Playwright 自己的产物（`test-results/`/`playwright-report/`/`blob-report/`/`playwright/.cache/`）、一次性验证/排查脚本及其输出（`scratchpad/`/`tmp/`/`diag.js`/`edge.js`/`*.out.txt`/`*.dump.json`）。**验证**：`git ls-files` 逐个过 `git check-ignore`，确认**没有任何已入库文件被新规则误伤**；并确认例外规则真的生效（`assets/foo.png` → 可入库，根目录 `foo.png` → 忽略）。
  - **② 零余量位置改成规则化断言，不再依赖"人记得回来查"**。上一条只是把 `seat-faction ↔ seat-gen-name` 的 0px 间隙**写进 log**，那是被动的。现在在 `inspectSeat` 里加了 `minGap`：枚举卡内所有叶子元素两两的间隙（两轴取较大者，只要有一轴分开就不算重叠），**豁免"双方都在 `.seat-equip-bar` 内"的对**（相邻装备行 9px 字、`line-height:1.2` → 行距 10.8px vs 行盒 13px，名义重叠约 1.2px，但墨迹只有约 9px、实际不相碰，是排版的正常产物），其余一律要求 **间隙 ≥0**。**刻意不做成"脆弱位置清单"**——清单要人维护，等于把"依赖记忆"从一个地方搬到另一个地方；规则化之后将来新增的元素自动被覆盖。矩阵 30 格（2/4/6/8/9 人 × 844×390 / 667×375 / 932×430 × 对手卡/我的卡）全部通过，且**每一格最紧的一对都恰好是 `seat-faction↔seat-gen-name`**，说明规则自动锁定了全局最紧处，不需要任何人工指定。
  - **③ 鉴别力实测过程中推翻了自己上一条的结论（如实记录）**。先按上一条 log 里写的"字号 +1px 就会撞上"去扰动，把 `.seat-faction` 的 `font-size` 从 9px 调到 10px——**断言没红**；再把盒高 `12px→14px`——**还是没红**。查下来是我判断错了：`.seat-faction` 和 `.seat-gen-name` 是 `.seat-left` 这个 **flex column** 里的流式兄弟，间隙就是 `gap` 本身，前者长高只会把后者往下推，**结构上不可能重叠**；而且 `.seat-faction` 有固定的 `width/height`，改字号根本不改变几何。**所以那个 0px 根本不是脆弱点**，上一条记录里的告警是错的，已回头改正。真正可能重叠的是**跨容器的绝对定位元素**（🔖 撞装备条那次就是这一类）。改用正确的扰动重测：把 `.seat-identity-mark` 的 `top` 从 38% 调到 41% → 仍全绿（间隙尚未归零）；调到 **42% → `seat-identity-mark("🔖")↔B("武")` 间隙 -0.3px，新断言变红，而旧的重叠断言（容差 2px）仍然全绿**。这一组对照精确地证明了新断言的**增量价值**：它在重叠 0.3px 时就报，旧断言要到 2px 才报；并且它只在 667×375/9人局这一格触发，同时印证了矩阵化验证的必要性。
  - **教训（已补进 `docs/progress-log-index.md` 第二节）**：**"这里余量只剩 0，很危险"这句话本身也是一个需要验证的断言，不能凭数值小就下结论**——同样是 0px，flex 流式兄弟之间是结构性安全的，绝对定位元素之间才是真风险。**看到一个危险的数字时，先问它所处的布局结构允不允许它变负**，否则会像这次一样，把一个结构上不可能出问题的地方当成最脆弱处写进文档，同时真正的风险位置反而没被识别出来。
